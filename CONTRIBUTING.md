# Contributing Guidelines

Thank you for your interest in improving Excel Financial Systems!

## How to Contribute

### Reporting Issues
- Report bugs or suggest improvements by opening an issue
- Provide clear description and steps to reproduce

### Suggesting Enhancements
- Share ideas for new financial tools
- Propose formula improvements
- Suggest new features or categories

### Sharing Improvements
- Modified templates
- Better formulas or calculations
- Enhanced charts and visualizations

---

## File Standards

- Keep files organized and well-documented
- Use clear sheet names and cell labels
- Include data validation where appropriate
- Test before submitting

---

## Questions?

Feel free to ask for clarification or help!
